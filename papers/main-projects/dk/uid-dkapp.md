# UID and DkApp

First section written; the rest is open. See [Contributing](../../../CONTRIBUTING.md) to write it.

UID is the primary application of Drayker: a base interface, like an operating system, inside which the other applications are installed and run. A DkApp is an OSDK structure already assembled for a general or specific purpose: a combination of modules optimized for one application of the network, usually running as an internal application of UID. UID also works as the member's living record inside Drayker, under the member's control. None of this runs today.
