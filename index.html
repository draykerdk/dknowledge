PUBLIC / PRIVATE BOUNDARY

The public base is not the private workspace.

Dknowledger publishes material intentionally committed to draykerdk/dknowledge. Private vault content, personal context and agent memory are not copied into this site.

The long-term architecture may span public, federated and private knowledge. Today, only this public repository surface is claimed as operational.
